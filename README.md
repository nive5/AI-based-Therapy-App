# AI-based-Therapy-App

## 🧠 Project Overview

AI Therapy Assistant is a full-stack web application that provides AI-powered mental health support.  
It includes secure user authentication, real-time chatbot interaction, and a modern frontend interface.

### Tech Stack
- Backend: FastAPI, SQLAlchemy, JWT Authentication
- Frontend: Next.js, Tailwind CSS
- Database: SQLite / PostgreSQL
- AI: HuggingFace Transformers / OpenAI
